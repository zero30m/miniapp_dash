# 多语言文案修订记录

日期：2026-09-09。修订范围为英语、日语、韩语。

## 代码与文案的对应关系

- `utils/i18n/ui.js` 合并 `ui_extra.js`；校验与复核使用合并后的实际导出值。
- 卡牌通过 `utils/i18n/cards.js` 按主题、卡牌 ID 取译文，再由 `components/drinking-game/index.js` 合并进原卡。真心话 ID 有偏移；DIY 抓手指复用题库中的 133 道题。
- `finger_questions.js` 末尾的覆盖表优先于前面的基础表，检查时使用最终导出题目，避免改了基础表却没有生效。
- 在线扑克的按钮、阶段、出价和结果文案结合对应组件与 `roomManager` 的状态及动作含义检查。数据库结构以 `database.txt` 为参考，不能用旧介绍文档代替当前玩法。
- 当前页面使用奶油色背景、粗黑边、高饱和色块、大字号和部分英文全大写。长度检查依据现有 WXML/WXSS，没有修改字号、布局、截断或换行规则。

中文的最终导出文案保持不变。没有新增文案换行符，没有改动卡牌 ID、字段结构或插值占位符。

## 验证

执行：

```sh
node scripts/check-i18n.js
```

该脚本检查所有多语言 JS 文件的语法；核对英语、日语、韩语各 934 个界面字段；检查卡牌及抓手指题目的字段、ID 和占位符。允许英文量词等设计上留空的字段。

本轮还使用修改前的本地备份执行了：

```sh
node scripts/check-i18n.js --baseline /tmp/miniapp-i18n-before/i18n
```

通过检查：中文未变、没有删除既有字段、没有新增换行、占位符及其重复次数保持一致。临时备份仅用于本次验证，不是项目依赖。

本地 Chromium 排版模拟：

- 使用现有卡牌样式，按 320／375 CSS 像素屏宽转换 rpx。
- 检查三语共 5,382 个卡牌正面组合、126 个哲学家卡牌背面组合。
- 另外测量 36 组大厅标题、停止提示、三按钮区与竞价栏的单行文案；出价使用三位数占位值。
- 最终模拟未检出上述样本的溢出。自然换行的卡牌标题没有被统一当成单行字段。

这些结果限于本地浏览器字体与模拟容器，未通过微信开发者工具或真机运行验证；不覆盖任意长昵称、任意大金额、系统放大字体和所有页面动态状态。

## 预览注意

`utils/i18n/debug.js` 当前为 `LOCALE_DEBUG_SWITCH = 'chs'`，会强制简体中文。该设置保持原样。预览时可分别切到 `eng`、`ja`、`ko`，或用 `auto` 跟随微信语言。

云端文章、运营内容和图片内文字不属于本次静态语言包修订。首页还存在按语言处理动态中文内容的逻辑；这类内容不能靠修改语言包自动翻译。
